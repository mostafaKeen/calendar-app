📅 Bitrix24 Meeting Booking API

Custom REST-like endpoints that interact with the Bitrix24 calendar. These APIs allow you to fetch available users, get free time slots (with flexible search window), and automatically book the first free meeting slot for a specific user. All endpoints return JSON and support CORS.

GET /get_users.php

Returns a list of active Bitrix24 users. Useful for populating dropdowns (appointment owner selection) before booking.

📥 Request

No parameters required. Simple GET request.

GET /get_users.php

📤 Response (200 OK)

{
  "status": "success",
  "users": [
    {
      "id": "123",
      "name": "John Doe",
      "email": "john@example.com",
      "work_position": "Sales Manager"
    },
    {
      "id": "456",
      "name": "Jane Smith",
      "email": "jane@example.com",
      "work_position": "Product Owner"
    }
  ]
}

If the request fails, an error object is returned.

POST /get_free.php

Checks a specific user's calendar on a given date and returns all available time slots (15‑minute increments) that can accommodate a meeting of a given duration. You can define the start time and the search range.

📥 Request Body (JSON)

ParameterTypeRequirementDescription
ownerIdintegerRequiredUser ID (from get_users.php) whose calendar is checked.
datestringOptionalDate in YYYY-MM-DD. Default: today.
durationMinutesintegerOptionalMeeting length in minutes. Default: 30.
startHourintegerOptionalStart hour for search (0–23). Default: 9 (9 AM).
startMinuteintegerOptionalStart minute for search. Default: 0.
rangeMinutesintegerOptionalNumber of minutes to look forward from the start time. Default: 480 (8 hours).
⚙️ How it works: The API fetches all calendar events for the target user on the given date, then scans from startHour:startMinute forward in 15‑minute steps. It returns every time slot where the requested durationMinutes fits without overlapping existing events.

📤 Example Request

curl -X POST https://your-domain.com/get_free.php \
  -H "Content-Type: application/json" \
  -d '{
    "ownerId": 123,
    "date": "2026-03-30",
    "durationMinutes": 45,
    "startHour": 10,
    "startMinute": 0,
    "rangeMinutes": 360
  }'

📤 Success Response

{
  "status": "success",
  "available_slots": [
    {
      "start": "2026-03-30T10:00:00+03:00",
      "end": "2026-03-30T10:45:00+03:00"
    },
    {
      "start": "2026-03-30T10:45:00+03:00",
      "end": "2026-03-30T11:30:00+03:00"
    }
  ],
  "count": 2
}

⚠️ Error Response

{
  "status": "error",
  "message": "Invalid input parameters"
}

POST /book_meeting.php

Automatically finds the first available free slot (respecting busy events) for the given user on a specific date, and creates a calendar event. You control the search window and meeting details. If a free slot exists, the meeting is booked instantly.

📥 Request Body (JSON)

ParameterTypeRequirementDescription
ownerIdintegerRequiredUser ID of the meeting owner (the person whose calendar is used).
datestringOptionalDate in YYYY-MM-DD. Default: today.
durationMinutesintegerOptionalDuration in minutes. Default: 30.
startHourintegerOptionalSearch start hour. Default: 9 (9 AM).
startMinuteintegerOptionalSearch start minute. Default: 0.
rangeMinutesintegerOptionalHow many minutes forward to search. Default: 480 (8 hours).
namestringOptionalEvent title. Default: "Auto-booked Meeting".
descriptionstringOptionalMeeting description or agenda.
locationstringOptionalPhysical address, Zoom link, or room name.
colorstringOptionalEvent color (e.g. #9cbe1c).
text_colorstringOptionalText color for the event.
accessibilitystringOptionalAvailability status: busy or free. Default: busy.
importancestringOptionalEvent priority: normal, high. Default: normal.
private_eventstringOptionalY or N. Default: N.
is_meetingstringOptionalY enables meeting features (attendees, host). Default not set.
hostintegerOptionalMeeting host ID. Defaults to ownerId when is_meeting=Y.
attendeesarrayOptionalArray of user IDs to invite. Only used if is_meeting=Y.
remindarrayOptionalReminder settings. Default: [{"type":"min","count":15}] (15 min before).
🔍 Auto‑search logic: The API scans the calendar in 15‑minute increments starting from startHour:startMinute, up to rangeMinutes forward. The first slot that fits durationMinutes and does not overlap any existing event is selected and booked. After booking, the event ID is returned.

📤 Example Request (book a 30‑minute meeting with attendee)

curl -X POST https://your-domain.com/book_meeting.php \
  -H "Content-Type: application/json" \
  -d '{
    "ownerId": 123,
    "date": "2026-03-31",
    "durationMinutes": 30,
    "startHour": 10,
    "rangeMinutes": 300,
    "name": "Project Sync",
    "description": "Discuss Q2 roadmap",
    "location": "Zoom / Internal VC",
    "is_meeting": "Y",
    "attendees": [456, 789],
    "color": "#9cbe1c"
  }'

✅ Success Response

{
  "status": "success",
  "message": "Meeting booked successfully",
  "event_id": 2417,
  "slot": {
    "start": "2026-03-31T10:00:00+03:00",
    "end": "2026-03-31T10:30:00+03:00"
  },
  "api_response": { ... }
}

❌ No Free Slot Response

{
  "status": "error",
  "message": "Not Available",
  "details": "No free slots found within the specified range."
}

❌ Validation / Bitrix Error

{
  "status": "error",
  "message": "Not Available",
  "details": "Invalid event data (Bitrix error description)",
  "api_response": { ... }
}

📌 Common Notes & Integration Tips

  • Time zone: All endpoints use +03:00 (Bitrix24 timezone configured on the portal). Adjust if your portal uses a different zone.
  • CORS: All endpoints return Access-Control-Allow-Origin: * and support OPTIONS preflight.
  • Search step: Both get_free.php and book_meeting.php scan in 15‑minute intervals. The minimum bookable duration is 15 minutes, but you can set any duration multiple of 15 (recommended).
  • Event overlap detection: Overlap is strict: if any existing event occupies even a minute of the candidate slot, it is considered busy.
  • User ID source: Always fetch the latest user list from get_users.php to ensure valid ownerId and attendee IDs.
  • Meeting vs simple event: If you set "is_meeting": "Y", the event becomes a meeting and can include attendees and a host. Without that flag, it's a simple calendar event.

🚀 Quick Start Flow

  1. Call GET /get_users.php → retrieve user list, display in dropdown.
  2. Optionally call POST /get_free.php to preview free slots for a given user, date, and duration.
  3. Call POST /book_meeting.php with the selected user, date, duration, and meeting details → automatically finds and books the first free slot.
