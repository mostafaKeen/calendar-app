📅 Bitrix24 Meeting Booking API (Tool-Calls Protocol)

This API provides custom REST-like endpoints that interact with the Bitrix24 calendar using a tool-calls JSON structure. All requests are hardcoded to act on behalf of Mohamed Nady (nady@keenenter.com).

🔄 Protocol Note: The API now expects a nested message.toolCallList array in the request and returns a results array in the response. This allows batch processing of multiple tool calls in a single request.

POST /get_timeline.php

Checks the hardcoded user's calendar and returns a list of existing events (busy timeline) for a given date.

📥 Request Body (JSON)

{
  "message": {
    "type": "tool-calls",
    "toolCallList": [
      {
        "id": "call_123",
        "function": {
          "name": "get_calendar_timeline",
          "arguments": {
            "date": "2026-03-31"
          }
        }
      },
      {
        "id": "call_456",
        "function": {
          "name": "get_calendar_timeline",
          "arguments": {
            "date": "2026-04-01"
          }
        }
      }
    ]
  }
}

📤 Success Response

{
  "results": [
    {
      "toolCallId": "call_123",
      "result": {
        "status": "success",
        "user_id": 1,
        "date": "2026-03-31",
        "timeline": [
          {
            "id": "1234",
            "name": "Team Standup",
            "start": "2026-03-31T09:00:00+03:00",
            "end": "2026-03-31T10:00:00+03:00",
            "accessibility": "busy"
          }
        ],
        "count": 1
      }
    },
    {
      "toolCallId": "call_456",
      "result": {
        "status": "success",
        "user_id": 1,
        "date": "2026-04-01",
        "timeline": [],
        "count": 0
      }
    }
  ]
}

POST /get_free.php

Checks the hardcoded user's calendar and returns all available time slots (15‑minute increments).

📥 Request Body (JSON)

{
  "message": {
    "type": "tool-calls",
    "toolCallList": [
      {
        "id": "call_456",
        "function": {
          "name": "get_free_slots",
          "arguments": {
            "date": "2026-03-31",
            "durationMinutes": 30,
            "startHour": 10
          }
        }
      },
      {
        "id": "call_789",
        "function": {
          "name": "get_free_slots",
          "arguments": {
            "date": "2026-04-01",
            "durationMinutes": 60,
            "startHour": 9
          }
        }
      }
    ]
  }
}

📤 Success Response

{
  "results": [
    {
      "toolCallId": "call_456",
      "result": {
        "status": "success",
        "available_slots": [
          { "start": "2026-03-31T10:00:00+03:00", "end": "2026-03-31T10:30:00+03:00" }
        ],
        "count": 1
      }
    },
    {
      "toolCallId": "call_789",
      "result": {
        "status": "success",
        "available_slots": [
          { "start": "2026-04-01T09:00:00+03:00", "end": "2026-04-01T10:00:00+03:00" }
        ],
        "count": 1
      }
    }
  ]
}

POST /book_meeting.php

Automatically finds the first available free slot and creates a calendar event for the hardcoded user.

📥 Request Body (JSON)

{
  "message": {
    "type": "tool-calls",
    "toolCallList": [
      {
        "id": "toolcall_abc123",
        "function": {
          "name": "book_bitrix_meeting",
          "arguments": {
            "date": "2026-03-31",
            "durationMinutes": 30,
            "name": "Project Sync"
          }
        }
      },
      {
        "id": "toolcall_def456",
        "function": {
          "name": "book_bitrix_meeting",
          "arguments": {
            "date": "2026-03-31",
            "durationMinutes": 30,
            "name": "Follow-up Call"
          }
        }
      }
    ]
  }
}

📤 Success Response

{
  "results": [
    {
      "toolCallId": "toolcall_abc123",
      "result": {
        "status": "success",
        "event_id": 2417,
        "slot": {
          "start": "2026-03-31T10:00:00+03:00",
          "end": "2026-03-31T10:30:00+03:00"
        },
        "message": "Meeting booked successfully"
      }
    },
    {
      "toolCallId": "toolcall_def456",
      "result": {
        "status": "success",
        "event_id": 2418,
        "slot": {
          "start": "2026-03-31T10:30:00+03:00",
          "end": "2026-03-31T11:00:00+03:00"
        },
        "message": "Meeting booked successfully"
      }
    }
  ]
}

📌 Common Notes

  • Hardcoded User: All operations are performed for User ID 1 (Mohamed Nady). Any ownerId passed in arguments will be ignored.
  • Time zone: All endpoints use +03:00.
  • Protocol: The message.toolCallList can contain multiple calls. Each script will process only the tool calls matching its respective function (get_calendar_timeline, get_free_slots, or book_bitrix_meeting).
